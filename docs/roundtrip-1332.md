# 往復翻訳 1,332件の結果

日本語 → 英語 → 日本語 と往復させて、どの語が別の語に化けるかを測った。

- 実施日: 2026-09-15
- 件数: 1,332件(16年分の記事から各年100件前後)
- 単位: 記事の地の文まるごと(最大1,500字)
- 翻訳: `pid`(`pi --provider ollama-cloud --model deepseek-v4-flash:cloud`)
- 実装: `scripts/roundtrip_queue.py`

## 半分以上で語が入れ替わった

**690件 / 1,332件 (51.8%)** で、元の語が別の語になって戻ってきた。

## 生き残り率で、語が2層に分かれる

「往復しても同じ語が残る割合」を測ると、はっきり分かれた。

### 安定している語(英語に1対1の対応がある)

| 語 | 生き残り | 件数 |
|----|---------|------|
| モジュール | **100.0%** | 51 |
| ツール | 98.8% | 167 |
| パス | 96.2% | 131 |
| コンポーネント | 96.0% | 50 |
| 確認 | 94.7% | 171 |
| ルート | 92.9% | 28 |
| ブロック | 92.3% | 26 |
| アーキテクチャ | 92.0% | 25 |

### 不安定な語(日本語側に選択肢がある)

| 語 | 生き残り | 件数 |
|----|---------|------|
| **パーツ** | **20.0%** | 5 |
| **手段** | **25.0%** | 8 |
| **作り** | **48.0%** | **98** |
| 区切り | 63.6% | 11 |
| 構成 | 72.6% | 62 |
| チェック | 76.5% | 162 |
| 基盤 | 80.0% | 5 |
| 検証 | 81.0% | 42 |

## 「作り」が最も不安定だった

98件という十分な件数で、生き残りが **48%**。2件に1件は別の語になる。

置き換え先が定まらないのが特徴。

```
作り → ベース(9) / 確認(8) / 構成(8) / 検証(8) / 仕組み(4) / 構造(4) / チェック(4)
```

往復で消えた回数も **70回**で突出している(2位のベース24回の約3倍)。

**英語に安定した対応物がない**ということ。文脈によって
`structure` にも `configuration` にも `build` にもなるので、戻すと別の語に落ちる。

実データとも符合する。「作り」は 2015年 0.62% → 2026年 1.50% と伸びが鈍く、
AI以前の傾きは **-0.057** とマイナスだった。
**翻訳で揺れる語は、書き手からも選ばれていない。**

## カタカナ語は強い、ただし例外がある

外来語は概して安定している(モジュール100%、ツール98.8%、パス96.2%)。
英語から来た語なので、英訳して戻せば同じ形に帰る。

ところが例外がある。

| 語 | 生き残り | 化ける先 |
|----|---------|---------|
| パーツ | **20.0%** | 部品、コンポーネント |
| チェック | **76.5%** | 確認、検証 |
| フロー | 82.1% | 流れ |
| ベース | 82.4% | 作り、検証 |

**同じカタカナ語でも、日本語側に競合する和語があると不安定になる。**

「チェック」は76.5%で、残りは「確認」「検証」に化ける。
実データで「確認」が大きく増えていたのと整合する。

## 双方向に行き来する組み合わせ

上位の置き換えを見ると、和語とカタカナ語が互いに行き来している。

| 元の語 | 戻った語 | 回数 |
|--------|---------|------|
| 構成 | 構造 | 21 |
| **チェック** | **確認** | 18 |
| **流れ** | **フロー** | 13 |
| 確認 | 検証 | 9 |
| **部品** | **コンポーネント** | 4 |
| **フロー** | **流れ** | 4 |
| **道具** | **ツール** | 3 |
| **インフラ** | **基盤** | 3 |

「流れ ⇄ フロー」「確認 ⇄ チェック」は**双方向に出ている**。
翻訳器から見て等価ということで、実データで両方増えていたのと合う。

## 読み取れること

生き残り率は、**その語に選択の余地があるかどうか**を表している。

- 生き残り率が高い = 英語に1対1で対応する = 書き手に選択の余地がない
- 生き残り率が低い = 日本語側に複数の候補がある = 書き手が選んでいる

「作り」48%、「チェック」76.5% のような**中間層が、日本語の語彙選択が
実際に動いている場所**ということになる。

[metaphor-vocabulary.md](metaphor-vocabulary.md) で観測した多極化
(2015年はカタカナ語の一強 → 2026年は和語が加わる)は、
この「選択の余地がある語」で起きていた。

## 限界

- **翻訳器のモデルに依存する。** 別のモデルなら結果は変わる
- **1回の往復しか見ていない。** 何度も往復させれば収束先が見えるかもしれない
- **検出しているのは「翻訳器が揺らす語」であって「AIが好んで使う語」ではない。**
  実データの発見と独立に一致したので価値はあるが、単独では証拠にならない
- 失敗100件(7.0%)。20並列にした際の 429 が大半で、4並列に戻してからは
  ほぼ増えていない
