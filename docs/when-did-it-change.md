# 変化はいつ始まったか

2020年と2026年で文体が変わったことは分かった。では**いつから**変わったのか。
各年8月を同じ物差しで並べて判定した記録。

- 実施日: 2026-09-14
- 対象: Qiita 各年8月(季節性を揃えるため月を固定)
- 判定: `scripts/detect_change.py`

## 閾値は取得前に固定した

結果を見てから「変化あり」の線引きを決めると後付けになる。
そこで **2021〜2025年を取得する前に**、AI以前(2019年3〜8月)の
月次変動幅から閾値を確定させ、`data/interim/change_threshold.json` に保存した。

| 指標 | 2019年の月次変動幅 | 閾値(幅の3倍) |
|------|------------------|--------------|
| 漢字率 | 0.001 | 0.004 |
| burstiness | 0.005 | 0.014 |
| 体言止め | 0.005 | 0.016 |
| 地の文字数 | 47字 | 141字 |
| MTLD | 0.260 | 0.876 |
| 読点/文 | 0.023 | 0.069 |

「AI以前の月次のゆらぎの3倍を超えたら、ゆらぎでは説明できない」という基準。

### 閾値を超えた最初の年

| 年 | 指標 |
|----|------|
| 2021 | MTLD(ただし2026年と逆方向) |
| **2022** | **burstiness** |
| **2023** | **地の文字数、漢字率、体言止め、読点/文** |
| 2026 | 箇条書き、まとめ見出し |

**2023年8月に4指標が一斉に超えた。** ChatGPT の公開は2022年11月なので、
その9か月後にあたる。時期は符合する。

## burstiness だけ AI 公開より前に下がり始めている

ただし**きれいな話にはならない**。burstiness は2022年8月に動いており、
これは ChatGPT 公開(2022年11月)の**3か月前**にあたる。

| 期間 | burstiness |
|------|-----------|
| 2019年3〜8月 | -0.233 〜 -0.237 (幅 0.004) |
| 2020-08 | -0.234 |
| 2021-08 | -0.233 |
| **2022-08** | **-0.257 (-0.022 ●)** |
| 2023-08 | -0.260 |
| 2026-08 | -0.287 |

3年半ほとんど動かなかった値が、2022年8月に突然 0.022 動いた。
**時系列的に生成AIでは説明できない。**

考えられる説明:

- Qiita の編集画面や推奨テンプレートの変更
- 記事ジャンルの構成変化(2022年は記事数が 4,461 と、2019年の 5,830 から
  減っている。書き手の層が変わった可能性)
- GitHub Copilot(2021年6月一般公開)の影響。コード補完だが、
  文章にも間接的に影響した可能性はある
- 単なる偶然(8月1点しか見ていないため)

**どれも検証していない。** この点は未解決のまま残す。

## 2021年は判定できない

8指標のうち **7つが閾値内**。2019年・2020年と区別がつかない。

ChatGPT の公開は2022年11月なので、その1年以上前の2021年が
AI以前と同じ姿をしているのは筋が通る。

### 唯一の例外 MTLD は、方向が逆

MTLD(語彙多様性)だけが閾値を超えたが、**2026年とは逆向き**に動いている。

| 年 | MTLD | 基準との差 |
|----|------|-----------|
| 2019-03〜08 | 43.68〜43.94 | ±0.14 以内 |
| 2020-08 | 43.11 | -0.69 |
| 2021-08 | **42.58** | **-1.27 ●** |
| 2026-08 | **53.03** | **+9.23 ●** |

2019 → 2020 → 2021 と**一貫して下がり続けて**いて、単発の異常ではない。
その後2026年には逆に大きく上昇する。

つまり2021年の MTLD 低下は、2026年の上昇とは別の現象。
AI の影響なら語彙が豊かになる方向(上昇)に出るはずで、
下降トレンドを AI で説明するのは無理がある。

2022〜2025年が揃えば、この下降がどこで底を打って反転したかが見える。


## AI以前のトレンドを延長しても届かない

2019→2021(すべてAI以前)の動きを見ると、2026年とは**方向が違う**。

| 指標 | 2019→2021 | 2021→2026 | 判定 |
|------|-----------|-----------|------|
| 体言止め | **+0.013**(増加) | **-0.119**(激減) | **反転** |
| MTLD | **-1.10**(減少) | **+10.45**(急増) | **反転** |
| burstiness | +0.002(ほぼ静止) | -0.054 | 新規の動き |
| 漢字率 | +0.004 | +0.055 | 同方向だが14倍に加速 |
| 地の文字数 | +67.5字 | +978字 | 同方向だが14倍に加速 |

体言止めと MTLD は **AI以前のトレンドと逆向きに動いている**。
元の傾向を延長しても2026年の値には届かず、むしろ反対側に行く。

これは「元からの傾向が続いただけ」という説明を否定する。
[monthly-baseline.md](monthly-baseline.md) が「AI以前は動かない」ことを示し、
本節は「動いていた分も方向が違う」ことを示している。

漢字率と地の文字数は同じ方向だが、**2年で +0.004 / +67字 だったものが
5年で +0.055 / +978字**。年あたりに直すと7倍前後の加速で、
連続的な延長では説明しにくい。


## 閾値の係数を変えたらどうなるか(感度分析)

「3倍」という係数に理論的根拠はない。そこで係数を変えて、
結論が変わるかを実測した。表は閾値を超えた指標の数(8指標中)。

| 係数 | 2019 | 2020 | 2021 | 2026 |
|------|------|------|------|------|
| 1倍 | 0/8 | 1/8 | **5/8** | 8/8 |
| 2倍 | 0/8 | 0/8 | **3/8** | 8/8 |
| **3倍(採用)** | 0/8 | 0/8 | **1/8** | 8/8 |
| 5倍 | 0/8 | 0/8 | 0/8 | 8/8 |
| 10倍 | 0/8 | 0/8 | 0/8 | 7/8 |

### 頑健な部分

**2026年は係数を10倍にしても7指標が超える。** AI以前と明確に違うという
結論は、閾値の選び方に依存しない。2019年は逆に、1倍にしても0/8のまま。

### 頑健でない部分

**2021年の判定は係数に強く依存する。** 1倍なら5指標、2倍なら3指標、
3倍なら1指標。「2021年はAI以前と区別がつかない」という結論は、
**3倍を選んだから出たもの**であって、係数次第では「すでに動き始めていた」
とも読める。

1倍で超える5指標を見ると、体言止め(0.167、基準0.152)と
地の文字数(1,058字、基準969字)が含まれる。どちらも2026年と同じ方向。
2021年時点で微妙に動き始めていた可能性は否定できない。

ただし1倍は「AI以前の月次変動幅と同じ」なので、
月ごとのゆらぎと区別できない水準でもある。
**2021年については「判定できない」が正確な答え。**

## この分析の位置づけ

[monthly-baseline.md](monthly-baseline.md) で「AI以前の文体はほとんど動かない」
ことを示した。本稿はその物差しを各年に当てて、**どの年から外れ始めたか**を見る。

2019〜2023年と2026年が揃った。2024〜2025年は取得中で、
埋まれば2023年以降の動き方(段階的か一気か)が見える。

## 限界

- **8月だけ。** 季節性を揃えるために月を固定したが、
  他の月で違う動きをしている可能性は排除できない。
- **中央値のみ。** 分布の形が変わっていないかは見ていない。
- **閾値の3倍という基準は恣意的。** 事前に固定したので後付けではないが、
  3倍という係数自体に理論的根拠はない。感度分析(上記)の結果、
  2026年の判定は係数に頑健だが、**2021年の判定は係数次第で変わる**。
- **変化が連続的なら「開始年」は決まらない。** 閾値をまたいだ年は
  「観測できるようになった年」であって、変化が始まった年とは限らない。
