# 変化はいつ始まったか

2020年と2026年で文体が変わったことは分かった。では**いつから**変わったのか。
各年8月を同じ物差しで並べて判定した記録。

- 実施日: 2026-09-14
- 対象: Qiita 各年8月(季節性を揃えるため月を固定)
- 判定: `scripts/detect_change.py`

## 閾値は取得前に固定した

結果を見てから「変化あり」の線引きを決めると後付けになる。
そこで **2021〜2025年を取得する前に**、AI以前(2019年3〜8月)の
月次変動幅から閾値を確定させ、`data/interim/change_threshold.json` に保存した。

| 指標 | 2019年の月次変動幅 | 閾値(幅の3倍) |
|------|------------------|--------------|
| 漢字率 | 0.001 | 0.004 |
| burstiness | 0.005 | 0.014 |
| 体言止め | 0.005 | 0.016 |
| 地の文字数 | 47字 | 141字 |
| MTLD | 0.260 | 0.876 |
| 読点/文 | 0.023 | 0.069 |

「AI以前の月次のゆらぎの3倍を超えたら、ゆらぎでは説明できない」という基準。

## 2021年はまだ「AI以前」だった

8指標のうち **7つが閾値内**。2019年・2020年と区別がつかない。

ChatGPT の公開は2022年11月なので、その1年以上前の2021年が
AI以前と同じ姿をしているのは筋が通る。

### 唯一の例外 MTLD は、方向が逆

MTLD(語彙多様性)だけが閾値を超えたが、**2026年とは逆向き**に動いている。

| 年 | MTLD | 基準との差 |
|----|------|-----------|
| 2019-03〜08 | 43.68〜43.94 | ±0.14 以内 |
| 2020-08 | 43.11 | -0.69 |
| 2021-08 | **42.58** | **-1.27 ●** |
| 2026-08 | **53.03** | **+9.23 ●** |

2019 → 2020 → 2021 と**一貫して下がり続けて**いて、単発の異常ではない。
その後2026年には逆に大きく上昇する。

つまり2021年の MTLD 低下は、2026年の上昇とは別の現象。
AI の影響なら語彙が豊かになる方向(上昇)に出るはずで、
下降トレンドを AI で説明するのは無理がある。

2022〜2025年が揃えば、この下降がどこで底を打って反転したかが見える。


## AI以前のトレンドを延長しても届かない

2019→2021(すべてAI以前)の動きを見ると、2026年とは**方向が違う**。

| 指標 | 2019→2021 | 2021→2026 | 判定 |
|------|-----------|-----------|------|
| 体言止め | **+0.013**(増加) | **-0.119**(激減) | **反転** |
| MTLD | **-1.10**(減少) | **+10.45**(急増) | **反転** |
| burstiness | +0.002(ほぼ静止) | -0.054 | 新規の動き |
| 漢字率 | +0.004 | +0.055 | 同方向だが14倍に加速 |
| 地の文字数 | +67.5字 | +978字 | 同方向だが14倍に加速 |

体言止めと MTLD は **AI以前のトレンドと逆向きに折れている**。
元の傾向を延長しても2026年の値には届かず、むしろ反対側に行く。

これは「元からの傾向が続いただけ」という説明を否定する。
[monthly-baseline.md](monthly-baseline.md) が「AI以前は動かない」ことを示し、
本節は「動いていた分も方向が違う」ことを示している。

漢字率と地の文字数は同じ方向だが、**2年で +0.004 / +67字 だったものが
5年で +0.055 / +978字**。年あたりに直すと7倍前後の加速で、
連続的な延長では説明しにくい。

## この分析の位置づけ

[monthly-baseline.md](monthly-baseline.md) で「AI以前の文体はほとんど動かない」
ことを示した。本稿はその物差しを各年に当てて、**どの年から外れ始めたか**を見る。

現時点で言えるのは「2021年はまだ外れていない」ことまで。
2022〜2025年は取得中。

## 限界

- **8月だけ。** 季節性を揃えるために月を固定したが、
  他の月で違う動きをしている可能性は排除できない。
- **中央値のみ。** 分布の形が変わっていないかは見ていない。
- **閾値の3倍という基準は恣意的。** 事前に固定したので後付けではないが、
  3倍という係数自体に理論的根拠はない。2倍なら2021年の体言止め(0.167)も
  超えていた可能性がある。
- **変化が連続的なら「開始年」は決まらない。** 閾値をまたいだ年は
  「観測できるようになった年」であって、変化が始まった年とは限らない。
