# 生き残り率と AI語彙辞書は、役割が重ならない

往復翻訳で測った「生き残り率」を lint に入れるべきか判断するため、
p1ass さんの
[textlint-rule-preset-ai-words-ja](https://github.com/p1ass/textlint-rule-preset-ai-words-ja)
と突き合わせた。

**結論: 両者はほぼ重ならない。併用するのが正しい。**

- 実施日: 2026-09-15
- 往復翻訳: 1,744件(第1弾1,332 + 第2弾412)、53語で生き残り率を算出

## 重なりは72語中9語だけ

| | 語数 |
|---|------|
| こちらの対象語 | 72 |
| p1ass 辞書 | 62 |
| **重なり** | **9** |

重なった9語: 入口、土台、照合、突き合わせる、経路、線引き、走る、道具、部品

そのうち往復翻訳で8件以上を測れた語は**ゼロ**。判断材料にならない。

## 重ならない理由は設計思想の違い

| | p1ass 辞書 | こちらの対象語 |
|---|---|---|
| 語の例 | 実測、効く、壊れる、事故、帰結、定石 | ツール、パス、モジュール、チェック、フロー |
| 選び方 | **AI が使いがちな語**(観察 → 実測で検証) | **同じ概念に複数の言い方がある語**(概念グループ) |
| 検出するもの | その語が出たこと自体 | どの語を選んだか |

p1ass さんは「実測」「帰結」のような**単独で目立つ語**を集めている。
こちらは「ツール ⇄ 道具」のように**言い換えが存在する語**を集めた。

目的が違うので、集合がほぼ交わらない。

どれも英語側が複数に散る(手段 = means / way / method、
動作 = operation / behavior / action)。

## lint に入れるかの判断

**入れない。** 理由は2つ。

1. **p1ass 辞書と役割が違うので、併用すればよい。**
   語彙の検出はあちらに任せ、こちらは構文と指標を見る
2. **生き残り率が低い = 直すべき、ではない。**
   「作り」45.9% は「英語に対応物がない」ことを示すだけで、
   使ってはいけない語という意味ではない

生き残り率は**書き手に選択の余地があるかを測る指標**であって、
良し悪しの判定ではない。lint に入れると「低い語を避けろ」という
誤ったメッセージになる。

ただし[往復翻訳の結果](roundtrip-1332.md)自体は、
語彙の多極化を説明する材料として価値がある。記事には反映済み。

## 限界

- 重なった9語で件数が足りず、**直接の比較ができていない**。
  同じ語で生き残り率と AI 語彙率の相関を見るには、
  p1ass 辞書の語を対象に往復翻訳を回す必要がある
- こちらの対象語は手で選んだ概念グループ。網羅的ではない
