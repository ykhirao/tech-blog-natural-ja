# 日本語技術記事を書く / 直すためのプロンプト

Qiita 6,952本(生成AI以前の2020年8月)と10,264本(2026年8月)を実測して得た
知見をプロンプト化したもの。Claude Code / Codex などのコーディングエージェント、
あるいは通常のチャットにそのまま貼って使う。

**このプロンプトは「AIっぽさ」を消すためのものではなく、読みやすい技術記事を
書くためのもの。** 実測すると、世間で「AIっぽい」とされる特徴の多くは
的外れだった(後述)。

---

## そのまま使うプロンプト

```
日本語の技術記事を書く(または直す)。以下は Qiita 約17,000本の実測から得た指針。

## 文のリズム

- 文の長さを揃えない。短い文と長い文を混ぜる。
  実測: 生成AI以前の記事は burstiness(文長のばらつき指標)の中央値が -0.234。
  AIが書いた文章は -0.28 付近に寄り、長さが揃う傾向がある。
- 「直せ」と言われて全部短くするのは誤り。短文ばかりに揃えても均質は均質のまま。
  長い文と短い文の落差を作る。
- 体言止めを使ってよい。
  実測: 2020年の技術記事は文の19.0%が体言止め。2026年は8.3%まで減った。
  体言止めがゼロの文章は、人間的な修辞が欠けて見える。

## 語彙と表記

- 漢字を増やしすぎない。
  実測: 2020年は地の文の17.4%(中央値)が漢字。2026年は23.4%まで上昇した。
  30%を超えると明確に硬い。ひらがなで書ける語はひらく。
- 「下記」「上記」を使わない。
  実測: 「下記」は17.7% → 4.2%(0.2倍)と激減した表現。
  「次のように」「先ほどの」など、読んだときに自然な語を使う。
- 読点は1文に1個前後。多いなら文を分ける。
  実測: 中央値0.52個。1.8個を超えると読みにくい。

## 構成

- 太字を多用しない。
  実測: 2020年は半数の記事が太字を1つも使っていない。
  強調が多いと、どれが重要か分からなくなる。
- 箇条書きに逃げない。説明できることは文章で書く。
  実測: 箇条書きの割合は11.3% → 22.1%と倍増した。
- 見出しを全部「結論形」に揃えない。
  全見出しを同じ書式にすると、それ自体がテンプレートに見える。
- 全部の節を同じ厚みで書かない。書くことがない節は短くてよい。

## やらないこと

- 「〜と言えるでしょう」「〜することが可能です」のような冗長な言い回し。
- 内容のない前置き(「本記事では〜について解説します」だけの段落)。
- 数値や固有名詞を出典なしで書く。確認できないなら書かない。
```

## 実測で覆った通説

プロンプトを作る際、「AIっぽい」とされる特徴を実際に測ったところ、
いくつかは逆だった。**思い込みで禁止語リストを作ってはいけない。**

| 通説 | 実測 |
|------|------|
| 「しましょう」はAIっぽい | 元記事の実測では**減っていた**(0.114→0.034/千字) |
| 文が長いのはAIっぽい | 平均文長の伸びは**AI以前からの傾向**で説明できる |
| 体言止めの多用はAIっぽい | 逆。**ゼロなのがAI的**(2020年19.0% → 2026年8.3%) |
| 「最後に」「まさに」はAI語 | coji氏の実測では**人間の日常語**(誤検知の63%を占めた) |
| 文頭の反復はAIっぽい | 逆。人間93% vs AI 41%で**人間の方が多い** |

## 検出できるが、直し方は書き手が決めること

このプロンプトと対になる textlint ルール
(`src/textlint/textlint-rule-qiita-tech-style.js`)がある。
書いたあとに機械で測って、参照分布から外れた箇所を教える。

```bash
npx textlint --rulesdir ./src/textlint --config .textlintrc.json 記事.md
```

ルールは「疑い」を提示するだけで、自動修正はしない。
固有名詞の反復のように、正当な理由がある場合は残してよい。

**重要**: このルールは「AIが書いたか」を判定しない。
指標値と参照分布上の位置だけを示す。非ネイティブ話者の誤検出率が
高いことが先行研究で示されており(Liang et al. 2023)、
文書単位の白黒判定は実在の書き手を不当に貶めるため。

## Goodhart の法則に注意

lint を通すことが目的化すると、それは新しい定型を生むだけ。
指標は下限であって目標ではない。数値を満たすために不自然な短文を挟めば、
今度は別の意味で機械的になる。
