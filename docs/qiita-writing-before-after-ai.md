# 生成AI以前と以後でエンジニアの文章はどう変わったのか（読書メモ）

## 1. 何をやった記事か

Qiita の記事を年をまたいで数え、生成AI普及の前後で「エンジニアの書く日本語」がどう変わったかを定量的に比べた分析記事。

期間区分:

| 区分 | 年 |
|------|-----|
| AI以前 | 2019–2022 |
| 移行期 | 2023–2025 |
| AI以後 | 2026 |

## 2. 方法論

**データ**

- Qiita API v2 で、各年 **8月** に投稿された記事を取得
- 取得 70,524 件 → 分析対象 **50,731 件**
- 除外: スライドモード記事 / 2022-11-30 以降に更新された旧記事 / 地の文 300 字未満 / 日本語以外

**前処理**

- Markdown を行単位で分類し、コード・表・見出し・箇条書きを分離 → **地の文だけ**を抽出
- 文の区切りは句点と行末。読点で終わる行は次行と連結
- 形態素解析は MeCab + UniDic

**統計**

- 予測値: 2019–2022 に直線を当てはめ 2026 まで外挿（「AIがなければこうなっていたはず」の線）
- 差の標準化: AI以前の標準偏差で正規化（Cohen の目安を適用）
- 信頼区間: **著者単位**のブートストラップ（復元抽出 ×1,000）
- 語彙: 対数オッズ比（informative Dirichlet prior）、excess vocabulary 法

> 著者単位でブートストラップしているのが誠実。多作な著者1人の癖が全体を動かすのを防いでいる。

## 3. 主要な発見

### 3-1. 記事の「組み立て方」が大きく変わった

| 指標 | AI以前平均 | 2026年 | 予測値との差(標準化) | 倍率 |
|------|-----------|--------|------|------|
| 地の文字数 | 976字 | 1,914字 | +0.89 | 約2倍 |
| 太字頻度 | 1.26/千字 | 3.83/千字 | +0.84 | 約3倍 |
| 箇条書き割合 | 8.9% | 16.4% | +0.57 | 約1.8倍 |
| 平均文長 | 35.4字 | 39.2字 | +0.01 | 予測値の範囲内 |
| 読点間文字数 | 21.2字 | 19.2字 | −0.17 | — |

**ポイント**: 長さ・太字・箇条書きは明確に増えた。一方 **平均文長の伸びは AI 以前からの傾向で説明でき、AI の影響とは言えない**。「文が長くなった＝AIっぽい」は雑な推論だということ。

### 3-2. AI以前はまれで 2026 年に広がった語彙

記事内の出現率（その語を含む記事の割合）:

| 語 | AI以前 | 2026年 |
|----|--------|--------|
| 効く | 2.0% | 22.3% |
| 瞬間 | 0.9% | 13.7% |
| 壊れる | 0.8% | 13.1% |
| 境界 | 1.0% | 12.8% |
| 実測 | 0.1% | 7.2% |
| 既定 | 0.5% | 7.1% |
| 別物 | 0.4% | 5.5% |

多くは 2025–2026 に一気に増加。著者は **英語概念の日本語対応物**である可能性を指摘（例: source of truth、silently → 「静かに」など）。

### 3-3. 増えた語 / 減った語

- **増えた**: 設計、判断、検証、運用、安全、失敗、承認、構造 → 抽象的・概念的
- **減った**: インストール、コマンド、設定、クリック、表示、ボタン → 手順的・操作的

記事の重心が「手順の記録」から「設計や判断の記述」へ移っている。

### 3-4. そのほかの変化

| 指標 | AI以前 | 2026年 | 備考 |
|------|--------|--------|------|
| 「まとめ」見出し | 12% | 52% | |
| ダッシュ「—」 | 0.04/千字 | 0.43/千字 | 約10倍 |
| です・ます調 | 50% | 66% | |
| 漢字割合 | 19.0% | 24.4% | |
| 「しましょう」 | 0.114/千字 | 0.034/千字 | **減少** |

### 3-5. 予想外の発見

「しましょう」「することが可能です」「また」といった、**世間で「AIっぽい」とされる表現はむしろ減っている**。

著者の解釈: AIっぽさが認識された結果、書き手が避けるようになったか、モデル側が修正している可能性。

## 4. 著者が明記している限界

- **因果は不明**。AIが書いた文章が増えたのか、人間の書き方が変わったのかを区別できない
- AI関連タグを除外しても、AI話題の記事は残っている可能性
- **生存バイアス**: AI以前の記事は「削除されずに残ったもの」だけ
- **季節性**: 8月のみの分析。他の月は不明
- Qiita の編集画面など**プラットフォーム側の変更**が指標に影響した可能性
- 予測値は「直線で伸びる」という仮定に依存
- 語の意味カテゴリー分けや言い回しの解釈は**著者の主観**

> 著者は「ある語が増えた理由がAIの文章にあるかは確かめていない」と明記している。

## 5. 結論（著者の3点）

1. **組み立て方は変わった** — 地の文約2倍、太字約3倍、箇条書き約1.8倍。ただし文長の伸びは AI 以前からの傾向で説明可能
2. **新しい語彙が急速に流入した** — 「実測」「既定」「入口」「事故」「別物」「効く」「静かに」など。多くは 2025–2026 に増加、英語概念の対応物の可能性
3. **「AIっぽい」とされた表現はむしろ減った** — 認識されたパターンは避けられるか修正される

## 6. このプロジェクトへの示唆

- 「AIっぽい日本語」の指標として実測値ベースの候補が得られる: 太字頻度、箇条書き割合、ダッシュ、「まとめ」見出し、漢字割合
- 逆に**使えない指標**も分かる: 平均文長（AI以前からの傾向）、「しましょう」（むしろ減少）
- ステレオタイプに基づく判定は外れる。**実測を指標選定の前提にする**
- 手法として、著者単位ブートストラップと「AI以前の直線外挿を予測値にする」やり方は流用できる
