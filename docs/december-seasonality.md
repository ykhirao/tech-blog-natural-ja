# 12月のずれは1月に戻る。しかも同じ人が書き方を変えている

[advent-calendar.md](advent-calendar.md) は2022年の8月→11月→12月が単調に
動くことから「年末に向けた連続的な変化」と書いた。
ただし**翌1月を見ていない。**

地の文の英字は3年とも12月に下がって1月に戻っていた
([english-in-prose.md](english-in-prose.md))。戻るなら連続変化ではなく
12月だけの逸脱になる。他の指標でも確かめる。[NEXT.md](NEXT.md) の宿題。

結論。

- 12月は**1月に戻る逸脱**だった。連続変化ではない
- 文の指標に強く出る。体言止めは **-2.54SD で12年とも同じ向き**
- 装飾の指標には出ない。太字・箇条書き・画像はゼロ付近
- **常連だけで測っても消えない。** 体言止めは -1.62SD で12年とも同じ向き。
  書き手の層が入れ替わるだけでなく、同じ人が12月は書き方を変えている

- 実施日: 2026-10-06
- 対象: 2014〜2025年の各12月と、その前後の11月・翌1月
- 手法: `scripts/december_effect.py`

## 測り方

各年について **12月 - (11月 + 翌1月)/2** を出す。これを戻り幅と呼ぶ。

- 12月だけの逸脱 → 11月と1月の両方から離れるので、ゼロから離れる
- 年末に向かう連続変化 → 12月は11月と1月の中間に来るので、ゼロに近い

指標ごとに単位が違うので、**12月以外の月のばらつき(SD)**で割る。
12年のうち何年が同じ向きに出たかも併記する。
向きが揃っていなければ、季節性ではなくその年の事情になる。

## 文の指標には強く出る

| 指標 | 戻り幅(SD) | 同じ向き |
|---|---|---|
| 体言止め | **-2.54** | 12/12 |
| 平均文長 | +1.85 | 12/12 |
| ですます | +1.67 | 12/12 |
| 地の文字数 | +1.53 | 12/12 |
| MTLD | +1.15 | 11/12 |
| 読点/文 | +0.96 | 12/12 |
| メリハリ | -0.61 | 12/12 |
| 見出し数 | +0.44 | 11/12 |
| 太字/千字 | -0.23 | 9/12 |
| 漢字率 | +0.19 | 11/12 |
| 箇条書き | +0.13 | 8/12 |
| 画像/千字 | -0.05 | 10/12 |

**体言止めが -2.54SD。** 12月以外の月のばらつきの2.5倍ずれる。
しかも12年すべて同じ向き。12月を跨いで月を比べると、
普段の月どうしの差の2.5倍の差が季節性だけで出る。

体言止めはこのプロジェクトの中心的な指標なので、
ここは気をつける必要がある。

**装飾の指標には出ない。** 太字(-0.23、9/12)、箇条書き(+0.13、8/12)、
画像(-0.05、10/12)はいずれもゼロ付近で向きも揃わない。
12月に変わるのは文の書き方のほうで、見た目の作りは変わらない。

[entry-cohorts.md](entry-cohorts.md) で入り口の変化が文(2022年)と
装飾(2025年)に分かれていたのと、同じ分かれ方をしている。

## 常連だけで測っても消えない

12月は非常連が63%を占める([advent-calendar.md](advent-calendar.md))。
層が入れ替わるせいなら、常連だけで測れば消えるはず。
その年の8月にも投稿した著者だけに絞る。

| 指標 | 全員 | 常連だけ | 同じ向き(常連) |
|---|---|---|---|
| 体言止め | -2.54 | **-1.62** | 12/12 |
| ですます | +1.67 | +1.09 | 11/12 |
| 地の文字数 | +1.53 | +1.08 | 12/12 |
| 平均文長 | +1.85 | +1.01 | 11/12 |
| MTLD | +1.15 | +0.88 | 11/12 |
| 読点/文 | +0.96 | +0.36 | 11/12 |
| 漢字率 | +0.19 | -0.00 | 6/12 |

**小さくなるが消えない。** 体言止めは -2.54 → -1.62 で、12年とも同じ向きのまま。
半分弱は非常連の流入で説明できるが、残りは常連自身の変化になる。

**同じ人が12月は違う書き方をしている。** 長く書き、ですますを増やし、
体言止めを減らす。アドベントカレンダーは書き手の層を変えるだけでなく、
書き方も変えている。

読点(+0.96 → +0.36)と漢字率(+0.19 → -0.00)は常連だと消える。
こちらは層の入れ替わりだけで説明がつく。

## 既存の結論は無事

12月を跨ぐ比較を使っている結論がないかを確かめた。

- [monthly-baseline.md](monthly-baseline.md) は3〜8月の6か月だけで、
  12月を含まない。「季節性は見ていない」と明記してある。
  この文書がそこを埋める形になる
- [within-author.md](within-author.md) は2月と8月
- [2020-08-vs-2026-08.md](2020-08-vs-2026-08.md) と
  [robustness.md](robustness.md) は8月どうし
- [full-timeline.md](full-timeline.md) は189か月を並べたもので、
  特定の月の比較はしていない

**どれも12月を跨いでいない。** 訂正の必要はない。

**2月から10月まではすべてゼロ付近。** 絶対値の最大が 0.19 で、
12月の 2.09 とは桁が違う。

年度替わりの3月と4月に層の入れ替わりがあるかと思ったが、
体言止めは -0.04 と -0.03 で何も出ていない。
**気をつける必要があるのは12月だけ**ということになる。

### 11月と1月の値は12月の影響

11月(+0.86)と1月(+1.23)が12月と逆向きに膨らんでいる。これは測り方の
副作用で、11月と1月の基準には12月が入っているため。12月が下がれば、
その隣の月は基準が下がって相対的に高く出る。
**11月と1月に季節性があるのではない。**

12月の体言止めがこの表では -2.09、上の表では -2.54 と違うのは、
割る数が違うため。上は12月を除いた月のばらつき、
この表は全月のばらつきを使っている。12月自体の逸脱が
ばらつきを膨らませるので、こちらが小さく出る。

## 分かっていないこと

**なぜ12月は長く書くのかは分からない。** アドベントカレンダーは日付が
決まっているので準備期間が取れる、という説明が思いつくが測っていない。
下書きの期間は `created_at` だけでは分からない。

戻り幅は11月と1月の平均を基準にしている。11月や1月そのものに
季節性があれば、その分だけずれる。
