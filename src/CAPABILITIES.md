# 何ができて、何ができないか

このプロジェクトで**できること・できないこと・作れるデータ**の一覧。
迷ったらここを見る。

---

## 1分でわかる結論

| やりたいこと | できるか | 手段 |
|------------|---------|------|
| **AI が書いたか判定する** | ❌ **できない** | 理由は下の「なぜAI判定ができないか」 |
| AI っぽい文章を Qiita っぽく直す | ✅ できる | プロンプト [`prompts/ai-to-qiita.md`](prompts/ai-to-qiita.md) |
| 文章のどこが参照分布から外れているか見る | ✅ できる | `scripts/style_distance.py` |
| 書きながら機械的に指摘を受ける | ✅ できる | textlint [`textlint/`](textlint/) |
| 表記を自動で直す | ✅ できる | prh [`prh/`](prh/) + `textlint --fix` |
| 「AIっぽい語」で記事を選別する | ⚠️ 精度が出ない | 最有力語でも非AI記事の1.2〜6.7%を誤検知 |
| 新しい期間を追加して分析する | ✅ できる | `scripts/fetch_qiita.py --months YYYY-MM` |

---

## できること

### ✅ AI文章 → Qiita っぽい文章への変換

**プロンプト版がある。** [`prompts/ai-to-qiita.md`](prompts/ai-to-qiita.md)

そのまま貼って使える指示文。目標値はすべて実測値。

| 直す対象 | 目標(AI以前の中央値) | 2026年の現状 |
|---------|-------------------|------------|
| 文長のメリハリ(burstiness) | -0.234 | -0.281 |
| 漢字割合 | 17.4% | 23.4% |
| 体言止め率 | 15.5% | 8.3% |
| 読点/文 | 0.52 | 0.90 |
| 太字/千字 | 0(半数が未使用) | 3.17 |

**効果は未検証。** プロンプトを通す前後でズレがどう変わるかは測っていない。

### ✅ textlint ルール(疑いの指摘)

[`textlint/textlint-rule-qiita-tech-style.js`](textlint/textlint-rule-qiita-tech-style.js)

```bash
npx textlint --rulesdir ./src/textlint --config .textlintrc.json 記事.md
```

実測200本で校正済み。

| 対象 | 指摘される記事 |
|------|--------------|
| 2020年(AI以前)の記事 | **2.5%**(誤検知) |
| 2026年の記事 | **12.0%** |

自動修正はしない。判断は書き手に残す。

### ✅ prh 辞書(表記の自動修正)

[`prh/qiita-tech-style.yml`](prh/qiita-tech-style.yml)

```bash
npx textlint --config .prhrc.json --fix 記事.md
```

実測で大きく動いた語だけを収録。「下記」17.4%→4.7%、「とりあえず」9.4%→3.1%など。
ただし**「減ったから直す」ではなく、技術文書として書き換える理由が説明できる語だけ**。

### ✅ 分布上の位置を出す

`scripts/style_distance.py`

```
体言止め率        0.000    0.155  ●·········|·········· p0
漢字割合          0.476    0.174  ··········|········●· p95
```

判定は出さない。どこを直せばいいかだけ示す。

2020年の記事80本と2026年の80本で、ズレの中央値は **0.257 vs 0.489**。
約2倍の差はつくが**分布は重なる**ので、個々の記事の判定には使えない。

## なぜ AI 判定ができないか

「AIしか使わない語があれば判定できるのでは」を、**実データで確かめた**。
結論は、そういう語は無かった。

2020年で0.5%未満 → 2026年で3%以上に増えた語を83件見つけたが、
個々の記事を調べると使えなかった。

| 語 | 2020→2026 | AI記事率 | 非AI記事での出現 |
|----|-----------|---------|----------------|
| 実測 | 0.08% → 8.2% (105倍) | 61% | **6.7%** |
| 根拠 | 0.31% → 7.3% | 68% | 5.3% |
| 既定 | 0.39% → 6.9% | 53% | 7.0% |
| 自律 | 0.14% → 4.9% | **88%** | 1.2% |

「実測」で判定すると非AI記事の6.7%を誤検知する(1万本なら670本)。

最有力の「自律」(AI率88%)も、誤検知77本の中身は
「スクラム開発ガイド」「Azure SQL Databaseの基礎」など、
AIと無関係に「自律的なチーム」「自律型システム」と書いた記事だった。
**AI以前の2020年にも13本が使っている。**

つまり検出しているのは「AIが書いた文章」ではなく**「AIについて書いた記事」**。
話題の語であって文体の語ではない。

### 加えて、外部の根拠

| 出典 | 内容 |
|------|------|
| Liang et al. (*Patterns* 2023) | 非ネイティブ英語話者の**誤検出率61%** |
| Vanderbilt 大 | Turnitin の AI 検出を**停止**(FPR 1%でも年750名を誤認) |
| OpenAI | 自社検出器を**撤回** |
| Sadasivan et al. | 理論的な**検出不可能性を証明** |

Qiita には非ネイティブ日本語話者も書いている。
誤検出は実在の書き手を不当に貶めるので、判定機能は作らない。

**代わりに「分布からの距離」を出す。** 用途はほぼ同じで、誰も告発しない。

## 手元にあるデータ

取得済み **104,451件**。すべて再現可能(`scripts/fetch_qiita.py`)。

| 期間 | 記事数 | 状態 | 用途 |
|------|-------|------|------|
| 2019-03〜2019-08 | 各 9,200〜9,700 | 完了 | AI以前の基準(6か月分) |
| 2019-09 | 7,997 | 部分(残5日) | — |
| **2020-08** | **10,407** | 完了 | **参照プロファイルの基準年** |
| 2024-12 | 1,419 | 部分(残29日) | パイロットの残り |
| **2026-08** | **11,569** | 完了 | **比較対象(AI以後)** |

生成済みの中間データ:

| ファイル | 内容 |
|---------|------|
| `data/processed/metrics_*.jsonl` | 記事ごとの全指標(2019-08/2020-08/2024-12/2026-08) |
| `data/processed/metrics_nonai_*.jsonl` | AI話題を除いた部分集合 |
| `data/processed/vocab_*.json` | 語彙の対数オッズ比(6,026語 / 3,987語) |
| `data/interim/nominal_*.jsonl` | 体言止めの文脈(2020: 2,507文 / 2026: 2,814文) |
| `data/processed/excluded_*.jsonl` | 除外した記事と理由 |

## まだデータ化できること

手元のデータで**追加取得なしに**作れるもの。

### すぐ作れる

| 作れるもの | 材料 | 何に使えるか |
|-----------|------|------------|
| **月次推移(2019-03〜09)** | 取得済み6か月 | AI以前の季節変動を測る。いまは8月1点のみ |
| **タグ別のプロファイル** | `metrics_*.jsonl` の `tags` | Python記事とインフラ記事で文体が違うか |
| **人気度と文体の関係** | `likes` フィールド | 読まれる記事の文体の特徴 |
| **記事長別のプロファイル** | `chars_body` | 短い記事と長い記事で閾値を変えるべきか |
| **著者の熟練度別** | `user_items_count` | 初投稿者とベテランの文体差 |
| **除外基準の妥当性検証** | `excluded_*.jsonl` | 落とした記事を読み直して基準を調整 |

### 追加取得が要る

| 作れるもの | 必要な取得 | 所要 |
|-----------|-----------|------|
| 完全な時系列(2019-2026 全月) | 93か月 | 約10時間(レート枠1000/h) |
| アドベントカレンダー分析 | 各年12月 | 12月は6月の1.5〜2.2倍の記事数 |
| 常連/非常連の比較 | 同一年の複数月 | 「普段書かない人の日本語」 |

## 使い分け

```
記事を書く
  └→ prompts/qiita-tech-writing.md をエージェントに渡す

AI に書かせた記事がある
  └→ prompts/ai-to-qiita.md で直す
      └→ textlint で確かめる
          └→ prh --fix で表記を整える

記事のどこが変か知りたい
  └→ scripts/style_distance.py で分布上の位置を見る

これは AI が書いたのか知りたい
  └→ できない。上の「なぜAI判定ができないか」を読む
```
