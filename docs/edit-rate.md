# 公開後に直さない記事が、2倍に増えた

Qiita API は `created_at` と `updated_at` を返す。これまで使っていなかったが、
**推敲したかどうか**の代理指標になる。

一度も更新されていない記事は、書いて出してそれきりということ。
文体の指標とは別の角度から、書き方の変化が見える。

**結論: 未更新の記事が2017年の32.1%から2026年の64.4%へ、2倍になった。**

- 実施日: 2026-09-15
- 対象: 各年8月(1,133〜11,569本)
- 手法: `scripts/edit_rate.py`

## 2017年を底に反転している

| 年 | 記事数 | 未更新% | 即時修正% | 後日更新% |
|----|-------|--------|---------|---------|
| 2013 | 1,133 | 42.3 | 18.9 | 38.8 |
| 2015 | 4,067 | 35.9 | 16.2 | 47.8 |
| **2017** | 4,822 | **32.1** | 18.1 | **49.8** |
| 2019 | 9,309 | 37.3 | 16.7 | 46.1 |
| 2020 | 10,407 | 39.7 | 16.5 | 43.8 |
| 2021 | 8,145 | 38.2 | 15.0 | 46.7 |
| 2022 | 7,103 | 43.2 | 14.8 | 42.0 |
| 2023 | 6,920 | 45.1 | 13.8 | 41.1 |
| 2024 | 7,815 | 46.9 | 14.5 | 38.6 |
| 2025 | 9,263 | 52.7 | 15.3 | 32.0 |
| **2026** | 11,569 | **64.4** | 11.2 | **24.5** |

判定は3つに分けた。

- **未更新**: `created_at == updated_at`。一度も直していない
- **即時修正**: 更新まで1時間未満。誤字直しなど
- **後日更新**: 1時間以上あと。書き足しや修正

2017年に 32.1% で底を打ち、そこから9年間ずっと上がり続けている。
**後日更新は逆に 49.8% → 24.5% で半減。**

## 月次では2026年を通じて上昇

| 月 | 記事数 | 未更新% | 後日更新% |
|----|-------|--------|---------|
| 2026-02 | 9,464 | 57.3 | 29.2 |
| 2026-04 | 11,409 | 58.2 | 29.9 |
| 2026-06 | 12,590 | 59.5 | 29.1 |
| 2026-08 | 11,569 | 64.4 | 24.5 |
| 2026-09 | 5,394 | **70.0** | 18.5 |

止まっていない。

### ただし新しい月は「これから更新される」分が入っていない

データを取ったのは2026年9月14日。9月の記事は公開から数日しか経っていない。
古い記事には何年も更新の機会があった。

**この交絡は無視できない。** 2026年9月の 70.0% はそのまま読めない。

ただし2017年から2024年の推移(32.1% → 46.9%)は、
どの年も6年以上経っているので比較できる。
**この範囲だけでも 1.5倍**になっている。

## 文体の変化とは時期がずれる

| 指標 | 動き出した時期 |
|------|--------------|
| **未更新率** | **2017年**(底) |
| 本文の体言止め・文長のばらつき | 2022年 |
| 太字 | 2024年末 |
| タイトル | 2024〜2025年 |
| 辞書の語彙 | 2025年半ば |
| 本文の読点 | 2026年前半 |

**未更新率がいちばん早い。** 生成AIより5年早く動き始めている。

読める話としては、書いて出してそれきりという使い方が
2017年ごろから広がった。ただし**原因は確かめていない**。
Qiita の UI 変更、書き手の層の変化、他プラットフォームとの競争など
いくらでも説明はつく。

## 限界

- **新しい月ほど更新の機会が少ない。** 2025年以降の値は、
  この効果を含んでいる。年をまたいだ比較は2024年までが安全
- **更新の中身を見ていない。** 誤字1文字の修正も、全面書き直しも
  同じ「後日更新」になる
- 1時間という境目は決め打ち。誤字直しと書き足しを分ける根拠は測っていない
- 削除された記事は入っていない。残った記事だけを見ている
