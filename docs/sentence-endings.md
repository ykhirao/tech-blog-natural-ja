# 体言止めが減ったぶんは、「です」に置き換わった

体言止めが2021年の 0.158 から2026年の 0.048 へ3分の1になった
([zero-users.md](zero-users.md))。

ではその文は、何で終わるようになったのか。
減った、で話を終わらせると、置き換わった先が分からないままになる。
そこで文末表現を数えた。

- 実施日: 2026-09-15
- 対象: 2020年8月と2026年8月の各10日分(2,209本 / 3,336本)
- 判定: 地の文の文末を正規表現で分類。長い形から順に当てる

## 記事ごとの比率(中央値)

記事の長さが2020年の1,636字から2026年の3,090字へ倍近くなっているため、延べ数で数えると長い記事のぶんだけ多く見えてしまう。そこで延べ数ではなく
**記事ごとに比率を出して中央値**を取った。

| 文末 | 2020-08 | 2026-08 | 変化 |
|------|---------|---------|------|
| です | 6.67% | **14.81%** | **2.2倍** |
| ています | 0.00% | **4.17%** | 新規 |
| ません | 0.00% | **3.23%** | 新規 |
| ます | 18.75% | 23.71% | 1.3倍 |
| ました | 2.16% | 3.23% | 1.5倍 |
| である/だ | 0.00% | 0.00% | — |

**「です」が2.2倍**でいちばん動いている。

目を引くのは「ています」と「ません」で、2020年の中央値が0%だった。
半数以上の記事が一度も使っていない。

## 延べ数で見ても同じ

| 文末 | 2020-08 | 2026-08 |
|------|---------|---------|
| ます | 21.85% | 22.45% |
| です | 8.89% | **14.15%** |
| ました | 4.35% | 5.52% |
| ています | 3.49% | **5.40%** |
| ません | 2.64% | **5.02%** |
| でしょう | 0.31% | 0.15% |
| である/だ | 0.76% | 1.73% |

(2020年 96,115文 / 2026年 250,216文)

「ます」はほとんど動いていない(21.85% → 22.45%)。
動いたのは「です」「ています」「ません」。

## 読み方

体言止めで終わっていた文が、「〜です」で終わるようになった。

```
2020年: 「設定ファイルの配置場所。」
2026年: 「設定ファイルの配置場所です。」
```

どちらが良いという話ではない。
ただし、言い切って読み手に解釈を委ねる形が減り、主語と述語をそろえて最後まで説明しきる形が増えた、という方向は読み取れる。

逆に「でしょう」は減った(0.31% → 0.15%)。推量を避ける方向。

## 限界

- **各年8月の10日分だけ。** 全月では測っていない
- 文末の判定は正規表現。「〜するのです」と「〜です」を区別していない
- **因果は言えない。** 体言止めが減ったから「です」が増えたのか、
  「です」が増えたから体言止めが減ったのかは分からない。
  同時に起きていることしか示していない
- 「である/だ」の中央値が両年とも0%なのは、
  技術記事の大半が「です・ます」で書かれているため。
  この指標では差が見えない
