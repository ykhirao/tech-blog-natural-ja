# 12月（アドベントカレンダー）の日本語

12月は「普段書かない人が書く月」なので、書き手の層が変わる。
文体の差が出ても「AIの影響」か「書き手が違うから」か区別がつかない。
これは交絡になるので、常連・非常連に分けて測った。

- 実施日: 2026-09-14
- 対象: 2022年12月(11,824本)
- 手法: `scripts/advent.py`
- 常連の定義: 同じ年の8月か11月にも投稿している著者

## 12月は非常連が多数派

| 層 | 記事数 | 割合 |
|----|--------|------|
| 常連(8月/11月にも投稿) | 4,329本 | 36.6% |
| **非常連(12月のみ)** | **7,495本** | **63.4%** |

記事数は11,824本で、同じ年の8月(4,461本)の **2.65倍**。
アドベントカレンダーの効果がはっきり出ている。

## 非常連のほうが長く書いている

| 指標 | 常連 | 非常連 | 差 |
|------|------|--------|-----|
| 地の文字数 | 1,291 | **1,561** | +270 |
| 漢字率 | 0.174 | **0.186** | +0.012 |
| **体言止め** | **0.125** | **0.094** | **-0.031** |
| 読点/文 | 0.590 | **0.646** | +0.056 |
| MTLD | 44.03 | 45.71 | +1.68 |
| 文長ばらつき | -0.259 | -0.260 | -0.001 |

普段書かない人のほうが**長く、漢字が多く、読点も多い**。力が入っている。

**体言止めは逆に少ない**(0.094 vs 0.125)。
慣れた書き手ほど言い切る余裕がある、と読める。

## 12月そのものが特異

同じ2022年の8月・11月と比べる。

| 指標 | 8月 | 11月 | **12月** |
|------|-----|------|---------|
| 地の文字数 | 1,061 | 1,119 | **1,456** |
| 体言止め | 0.143 | 0.125 | **0.104** |
| 読点/文 | 0.545 | 0.565 | **0.626** |
| 漢字率 | 0.176 | 0.179 | **0.182** |
| MTLD | 43.31 | 43.79 | **45.07** |
| **文長ばらつき** | **-0.257** | **-0.259** | **-0.259** |

8月 → 11月 → 12月と**単調に動いている**。
12月だけ突出しているのではなく、年末に向けた連続的な変化。

### 文長のばらつきだけ季節の影響を受けない

地の文字数(1,061 → 1,456)や体言止め(0.143 → 0.104)が大きく動く中で、
**文長のばらつきは -0.257 → -0.259 → -0.259 とほぼ不変**。

この指標を分析の中心に置いている根拠が1つ増えた。
季節や書き手の層が変わっても動かないので、AI以前の基準として使いやすい。

## 限界

- **2022年の1年分だけ。** 他の年の12月と比べていない
  (2024-12 は2日分しか取得していない)
- **常連の定義が粗い。** 同じ年の8月・11月だけを見ているので、
  他の月に書いている人を非常連に数えている可能性がある
- **12月内の日別変動を見ていない。** アドベントカレンダーは
  1〜25日に集中するはずで、月末は普段と同じかもしれない
