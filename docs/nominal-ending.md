# 体言止めはどう使われているか

「体言止めを使え」という指針だけでは、使いどころが分からず機械的に混ぜる
ことになる。**AI以前(2020年8月)の Qiita 2,000本を実測して、実際の用法を調べた。**

- 集計日: 2026-09-14
- 手法: `scripts/nominal_context.py`
- 対象: 2,000記事 / 全80,543文 / 体言止め 2,507文(3.1%)
- うち「文として成立しているもの」1,521文を分析

## 通説は2つとも成り立たなかった

| 通説 | 実測(技術記事) |
|------|---------------|
| 短く切って余韻を出す | **直前より短いのは36%だけ**。平均は 27.6 → 32.7モーラで**むしろ長い** |
| 段落の末尾に置く | 冒頭31.8% / 中間35.8% / 末尾32.5% で**ほぼ均等** |

「体言止め＝短く言い切る」は、技術記事では当てはまらない。
実際に多いのは、**長い説明を最後まで書いて言い切る**用法。

例:

> NetFlowは、シスコ社が開発したトラフィックの詳細情報を収集するための技術。

> 故障が発生したときに、その影響が誤りとなって外部に出ないように訂正するシステム。

どちらも30モーラを超える長さがある。短い断片ではない。

## 実際の用法

実例から読み取れた型。割合は概数(自動分類は精度が出なかったため、
実例を読んで整理した)。

### 1. 定義・言い換え — 「〜という技術。」

用語を説明して言い切る。`です・ます` で終えるより、定義であることが際立つ。

> NetFlowは、シスコ社が開発したトラフィックの詳細情報を収集するための技術。

> SSDと比べ、大容量でも低価格なことが特徴。

**使いどころ**: 用語の初出。段落の冒頭に置いて、以降で詳しく説明する。

### 2. 操作の完了 — 「〜を実行。」

手順の中で、動作だけを短く示す。技術記事に固有の用法。

> モデルのトレーニングを実行。

> ブランチをmasterに変更

> タスクマネージャーで確認。

**使いどころ**: 手順の列挙。毎回「〜します」と書くと冗長になる箇所。
ただし全部の手順をこれで書くと、それはそれで単調になる。

### 3. 結果・状態の提示 — 「〜は以下の通り。」

調べた結果や状態を示して、次に具体を置く。

> 若年者と高齢者の退院済フラグがになっていない割合を並べて示すと以下の通り。

> CPIが0.90<1 ので、コストは計画値を超過

**使いどころ**: 表やコードブロックの直前。導入として置く。

### 4. 感想・評価の言い切り

筆者の判断を、断定を避けずに置く。

> 一人で頑張るのは自己満足。

> Azure を試すのは、また今度。

**使いどころ**: 段落の末尾。文章に人の気配が出る箇所。
ここが `です・ます` だと、急に硬くなる。

## 書くときの指針

実測から言えること。

1. **短くする必要はない。** 30モーラ超の説明文を言い切る用法が主流。
   「短く切る」と思い込んで断片を置くと、かえって不自然になる。
2. **位置は決まっていない。** 段落の冒頭・中間・末尾のどこでもよい。
   末尾に寄せる必要はない。
3. **定義と手順で使い分ける。** 用語の説明は段落冒頭、操作は手順の列挙中。
4. **連続させない。** 実測では体言止めは全文の3.1%。
   30文に1文の割合で、それ以上続けると箇条書きのようになる。

## なぜこれを調べたか

2020年から2026年で、体言止めの比率が **19.0% → 8.3%** に半減した
([2020-08-vs-2026-08.md](2020-08-vs-2026-08.md))。
coji 氏の実測でも「体言止めゼロが AI 的」(人間60% / AI 0%)とされている。

ただし「体言止めを増やせ」と指示するだけでは、使いどころを外した文が増える。
実際の用法を知らないと、直した結果がかえって不自然になる。

## この分析の限界

- **抽出の難しさ**: 素朴に「名詞で終わる文」を数えると、Markdown の見出し
  (`#まとめ`)、箇条書き(`・概要`)、コードの残骸が大量に混ざる。
  最初の実装では抽出結果の23%が8モーラ未満の断片で、
  文末語の上位が「作成・設定・クリック」という手順語だった。
  フィルタを3段階に分けて 7,160文 → 2,507文 まで絞ったが、
  **まだ名詞句の見出しが残っている可能性がある**。
- **用法の分類は手作業**: 正規表現による自動分類は85%が「その他」になり
  使い物にならなかった。上の型は実例を読んで整理したもので、
  網羅的でも排他的でもない。
- **2020年のみ**: 2026年側の用法を同じ方法で調べていない。
  減った体言止めが「どの用法から減ったか」は分かっていない。
