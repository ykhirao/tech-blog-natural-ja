# 「依存」は何の話で増えたのか

「依存」は2026年に記事の19.0%が使う語になった。SDK 系のどの語よりも
変化が大きいので、何を指しているのかを調べた。

- 実施日: 2026-09-15
- 対象: 各年8月の記事(地の文300字以上)

## 増加は本物だった

記事数や長文化では説明できない。

| 年 | 記事数 | 含む記事 | 千字あたり | 記事あたり |
|----|-------|---------|-----------|-----------|
| 2019 | 6,075 | 6.3% | 0.070回 | 0.11回 |
| **2022** | 4,695 | **4.9%** | **0.039回** | 0.08回 |
| 2026 | 10,598 | **19.0%** | **0.131回** | **0.38回** |

**2022年がボトム。** 2019年から2022年まで減り続け、そこから跳ね上がっている。

千字あたりで 0.039 → 0.131 (**3.4倍**)、記事あたりでは **4.75倍**。
正規化しても残るので、実質的な増加といえる。

## ただし、用法の構成比は変わっていない

機械的に分類したところ、割合はほぼ同じだった。

| 用法 | 2019 | 2026 |
|------|------|------|
| 依存関係 / パッケージ | 31.5% | 26.0% |
| 〜に依存する(一般) | 22.1% | 20.5% |
| 環境依存 | 4.0% | 1.5% |
| 依存性注入(DI) | 2.6% | 1.3% |
| その他(分類漏れ) | 39.9% | 50.7% |

**特定の用法が増えたのではなく、全用法が一様に増えている。**

「依存関係の管理やサプライチェーンの話が増えたのでは」という見立ては外れた。

## 2026年には、技術以外の「依存」も混ざる

実例を読むと、2019年と2026年で分野が違う。

**2019年**(パッケージ管理が中心)

- 「依存関係でパッケージ間で共通して使われている…」
- 「Apache Spark を組み込んでつかうために依存ライブラリを設定します」
- 「環境に依存しない package.json を作れる」

**2026年**(数学・物理・社会論が混ざる)

- 「状態遷移、即時報酬、方策が『現在の状態のみに依存する』」(マルコフ性)
- 「振れ角 φ, θ は質量に依存しません」(物理)
- 「外国人労働依存の構造が俎上に載る」(社会論)
- 「テール依存の推定に使えるのは全体の1%」(統計)

記事の題材そのものが広がったことの反映と思われる。

## 分類器の限界

「その他」が50.7%を占めており、分類として使い物になっていない。

原因は正規表現が「依存関係」「〜に依存する」しか拾えないこと。
以下を取りこぼしていた。

| 実例 | 本来の分類 |
|------|----------|
| 「特定のツールに依存せず」 | 一般(活用形の違い) |
| 「依存ゼロの100行で作り」 | パッケージ管理 |
| 「必要な依存を持たせ」 | DI |
| 「依存配列の話ではなく」 | React の依存配列 |
| 「依存型・篩型」 | 型理論 |
| 「テール依存の推定」 | 統計 |

**構成比が変わっていないという結論は、分類の精度に依存しない**
(絶対数と正規化後の値で判断しているため)。
ただし「どの用法が増えたか」を細かく言うには、分類器を作り直す必要がある。

## 未検証

- 分類器の改良(複合語「依存ゼロ」「依存配列」「依存型」を拾う)
- 2022年がボトムになる理由。他の語でも同じ形が出るか
- 「依存」を含む記事のタグ分布。数学・物理系の記事が増えたのかを確かめる
