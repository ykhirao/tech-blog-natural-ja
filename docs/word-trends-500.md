# 頻出500語の12年推移

頻度上位500語を機械的に選んで、2015〜2026年の各年8月で追跡した記録。

- 実施日: 2026-09-14
- 手法: `scripts/word_timeline.py`
- 出力: `data/processed/word_timeline.json`(全500語の年次データ)

## 先に注意点: 記事が長くなった分の見かけの増加がある

**記事出現率(その語を含む記事の割合)は、記事が長くなるだけで上がる。**

| 年 | 地の文の長さ(中央値) |
|----|-------------------|
| 2019 | 990字 |
| 2022 | 1,061字 |
| 2026 | **2,036字** |

2022→2026 で **1.92倍**。長い記事ほど、どんな語も含まれやすい。

実際に上位語を見ると、伸びが2つに分かれる。

| 語 | 2022 | 2026 | 倍率 | 判定 |
|----|------|------|------|------|
| 置く | 32.72 | 53.32 | **1.63倍** | 長さの伸び以下。実質は増えていない |
| 作る | 31.05 | 50.87 | **1.64倍** | 同上 |
| 実際 | 20.13 | 55.91 | 2.78倍 | 長さ超え |
| 仕組み | 7.61 | 31.79 | 4.18倍 | 明確に増加 |
| 検証 | 7.72 | 30.61 | 3.96倍 | 明確に増加 |
| 設計 | 6.34 | 40.66 | **6.41倍** | 明確に増加 |
| 判断 | 4.77 | 32.91 | **6.90倍** | 明確に増加 |

語の伸びの中央値は 3.46倍 で、記事長の伸び(1.92倍)を上回る。
**全部が見かけではないが、1.9倍前後の語は割り引いて読む必要がある。**

以下の表はこの補正をかけていない生の数字なので、
**倍率2倍未満の語は「増えた」と読まないこと。**

### 「置く」「作る」「動く」は見かけの増加

この3語は AI 以前の傾きがマイナス(-0.8前後)で、
2015年から2025年まで**ずっと減っていた**。2026年の増加は
記事が長くなった分で説明できる(倍率1.6倍前後)。

### 「設計」「判断」「整理」「検証」は本物

倍率が6倍前後あり、記事長の伸び(1.9倍)では説明できない。
[vocabulary-shift.md](vocabulary-shift.md) の「手順語から概念語へ」と一致する。

## 使い方

全500語のデータは `data/processed/word_timeline.json` にある。

```json
{
  "years": ["2015", ..., "2026"],
  "article_counts": {"2015": 2360, ...},
  "words": [
    {"word": "設計", "series": [3.64, ...], "pre_slope": 0.385, "post_slope": 8.580,
     "first": 3.64, "last": 40.66, "ratio": 11.17}
  ]
}
```

再実行:
```bash
./scripts/word_timeline.py --years 2015,...,2026 --top 500
```
